KASIR KANTIN FUTSAL - PROTOTIPE ANDROID

Fitur prototipe:
- Daftar produk contoh dan harga
- Tambah barang ke keranjang dengan tombol +
- Hitung total dan kembalian
- Simpan transaksi di penyimpanan lokal HP
- Kelola/tambah produk dan stok
- Stok berkurang ketika transaksi disimpan

Catatan:
- Ini adalah proyek sumber, belum berupa APK yang siap dipasang.
- Fitur cetak Bluetooth belum diimplementasikan; tombolnya hanya penanda agar printer dapat ditambahkan kemudian.
- Belum ada pengurangan stok saat memilih barang, hanya saat transaksi disimpan.
- Belum ada fitur edit/hapus produk dan laporan penjualan di tampilan.
- Uji dulu dengan transaksi contoh sebelum dipakai untuk pencatatan uang sungguhan.

Cara membangun APK:
1. Instal Android Studio di komputer.
2. Buka folder proyek ini melalui Android Studio.
3. Tunggu Gradle Sync selesai.
4. Pilih Build > Build APK(s).
5. APK debug biasanya muncul di app/build/outputs/apk/debug/app-debug.apk.

Persyaratan:
- Android Studio versi baru
- JDK yang disarankan Android Studio
- Koneksi internet pertama kali untuk mengunduh komponen Gradle

Package: com.example.kantinfutsalkasir
